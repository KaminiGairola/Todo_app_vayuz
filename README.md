# VAYUZ TODO APP 

A Flutter TODO application built using Hive local database and GetX state management.

Features
- Add, Edit, Delete TODO tasks
- Mark tasks as Completed / Pending
- Date-based categorization:
  - Yesterday
  - Today
  - Future
- Task filtering:
  - All / Completed / Pending / Date-wise
- Local storage using Hive (offline support)
- Clean and responsive UI
- Dark/Light theme support (if enabled)
